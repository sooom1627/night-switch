# Product

プロダクト定義（概要・基盤・Epic）。Story / Task は [GitHub Issues](https://github.com/sooom1627/night-switch/issues) を参照する。

# 1. 概要

## 1.1 プロダクト概要

本アプリは、寝るべきだと分かっているのに夜更かししてしまう人が、自分で決めた時刻に夜の行動を切り替えられるよう支えるモバイルアプリである。

介入するのは睡眠そのものではなく、夜の行動を切り替えるという意思決定である。

## 1.2 プロダクトビジョン

**完璧な人を作るのではなく、戻ってこられる人を作る。**

最終的なゴールは、アプリがなくても自分で夜を管理できるようになることである。

## 1.3 対象ユーザー

寝るべきだと分かっているのに夜更かししてしまう人（bedtime procrastination）を対象とする。

「眠くない」人は対象外とする。不眠症や概日リズムの後退（夜型）の可能性があり、就床時刻を守らせる設計と合わないためである。ストアの説明文でも明示する。

## 1.4 成功の定義

決めた時刻に行動を切り替えられたか。眠れたかどうかではない。

## 1.5 プロダクト原則

- **奪わない**: 導入の時間は就寝準備という義務ではなく、「自分の時間の後半」
- **本当の欲求に応える**: 夜更かしで埋めている欲求を、静かな形で満たす
- **閉じさせる**: 一日を「終わった」と感じられる儀式を置く
- **夜に考えさせない**: 選択肢は各段階で3つまで。推奨を最初から選択状態にしておく
- **区切りで止める**: 時刻を突きつける前に予告する
- **責めない**: 失敗という言葉、赤色、下がる数字を使わない
- **ご褒美を見える化する**: 一般論ではなく、本人自身のデータで示す
- **最小限にする**: 通知は少なく、入力は1タップで済ませ、改善は週に1つまで
- **自立へ向かう**: 介入は徐々に減らす

## 1.6 言葉の規則

命令しない、責めない、誘いかける。

| 使わない               | 使う                       |
| ---------------------- | -------------------------- |
| 寝る時間です           | そろそろ降りよう           |
| 失敗                   | 遅くなった                 |
| 〜してください         | 〜しよう／〜でも十分       |
| 連続記録が途切れました | 今日は戻る日               |
| 就寝準備               | ゆっくりする方の自分の時間 |

赤色、警告アイコン、下がるグラフは使わない。

# 2. 基盤

## 2.1 アプリケーション基盤

- React Native（Expo）で作る。ディレクトリ構造と開発の進め方は stamp-log と同じにする
- iOS を先行する
- iOS のビルドは EAS Build で行う
- 最初のリリースは Screen Time を使わず、朝の判定は本人の自己申告（1タップ）にする。Screen Time による自動判定は E-003 で後から足す

# 3. Epic

Epic の一覧はこの表を正とする（Epic に GitHub のマイルストーンは使わない。マイルストーンはリリースの単位で、そのリリースに含める Story と Task を入れる）。Story / Task は [GitHub Issues](https://github.com/sooom1627/night-switch/issues) に書き、Story 本文に `Epic: E-###` を書く。状態は 未着手 / 進行中 / 完了 のいずれかで、Story ブランチを切ったときと Story を `master` へマージするときに更新する（定義は [agile-workflow](../.cursor/rules/agile-workflow.mdc)）。

| ID    | タイトル                 | 状態   | ゴール                                                                                                             |
| ----- | ------------------------ | ------ | ------------------------------------------------------------------------------------------------------------------ |
| E-000 | プロジェクトセットアップ | 未着手 | stamp-log と同じ構成の Expo アプリが EAS Build で実機に入り、push ごとに CI（lint・format・typecheck・test）が通る |
| E-001 | 最初の質問               | 未着手 | 「本当は何したい？」から始まる質問（望む結果 → 障害 → プラン）に答え、ルールと導入メニューを決められる             |

| E-003 | Screen Time の判定       | 未着手 | 切り替え時刻以降に選んだアプリを使ったかを自動で判定し、朝の判定に使える                                           |
| E-004 | 朝と Miss 翌日           | 未着手 | 朝に1タップで切り替えられたかと今朝の調子を記録でき、遅くなった翌日は責められずに戻れる                            |
| E-005 | 週次                     | 未着手 | 1週間を1行で振り返り、改善を1つだけ選べる                                                                          |
| E-006 | 続きは明日               | 未着手 | やめにくいものを翌日に預け、選んだ時刻に1回だけ思い出させてもらえる                                                |
| E-007 | アプリのロック           | 未着手 | 自分で選んだアプリに、切り替え時刻以降のロックをかけられる（任意）                                                 |
| E-008 | データの見える化         | 未着手 | 切り替えた朝と遅くなった朝の調子の違いなど、本人のデータでご褒美が見える                                           |
